# Приказ голосом

Визуальное Windows-приложение (Electron/Node.js): запись голоса с микрофона и отправка
в LLM-провайдера [polza.ai](https://polza.ai) (OpenAI-совместимый API) для транскрибации.

## Запуск в режиме разработки

```bash
npm install
npm start
```

При первом запуске откройте настройки (значок ⚙ в правом верхнем углу) и укажите:

- **API-ключ** — ключ polza.ai
- **Base URL** — по умолчанию `https://api.polza.ai/v1`
- **Модель транскрибации** — по умолчанию `whisper-1` (уточните точное название в личном
  кабинете polza.ai, если отличается)
- **Язык** — необязательный код ISO (например `ru`), можно оставить пустым

Настройки сохраняются локально в файле профиля пользователя и не попадают в код.

## Использование

1. Нажмите круглую кнопку с микрофоном — начнётся запись.
2. Нажмите ещё раз, чтобы остановить — запись автоматически отправится на транскрибацию.
3. Текст появится в поле снизу, его можно скопировать кнопкой «Копировать».

## Сборка .exe для Windows

```bash
npm run dist
```

Готовый установщик (NSIS) появится в папке `dist/`.
