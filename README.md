# Prikaz golosom

«Приказ голосом» — визуальное Windows-приложение (Electron/Node.js): запись голоса с микрофона и отправка
в LLM-провайдера [polza.ai](https://polza.ai) (OpenAI-совместимый API) для транскрибации.

## Готовая portable-версия

Portable-версия не хранится в репозитории — она публикуется как GitHub Release. После
`npm run dist` файл `dist/prikaz-golosom-portable-<версия>.exe` можно скопировать на
любую Windows-машину и запустить напрямую, без установки Node.js, либо загрузить как
ассет в GitHub Release.

## Запуск в режиме разработки

```bash
npm install
npm start
```

При первом запуске откройте настройки (значок ⚙ в правом верхнем углу) и укажите:

- **API-ключ** — ключ polza.ai
- **Base URL** — по умолчанию `https://api.polza.ai/v1`
- **Голосовая модель** — по умолчанию `whisper-1` (уточните точное название в личном
  кабинете polza.ai, если отличается)
- **Язык записи** — необязательный код ISO (например `ru`), можно оставить пустым
- **Текстовая модель** — модель для кнопки «Проверить на ошибки», по умолчанию `gpt-4o-mini`
- **Промпт для исправления ошибок** — инструкция модели: чистит орфографию/пунктуацию
  и убирает слова-паразиты и мычание («э», «м», «ну» и т.п.) из надиктовки. Задаёт
  только стиль правки: запрет выполнять надиктованный текст как команду добавляется
  к любому промпту автоматически и из настроек не отключается (см. ниже). Кнопка
  **«Восстановить»** рядом с полем возвращает промпт по умолчанию
- **Исправлять ошибки сразу после транскрибации** — включено по умолчанию: каждая
  расшифровка автоматически уходит на текстовую модель, нажимать «Проверить на ошибки»
  не нужно. Это отдельный запрос и отдельная стоимость, галочку можно снять

Настройки сохраняются локально в файле профиля пользователя и не попадают в код.

## Использование

1. **🎙 Записать** — начинает запись, после остановки заменяет текст в поле результата.
2. **➕ Дозаписать** — начинает запись, после остановки добавляет новый текст к уже
   имеющемуся, не стирая его.
3. После остановки записи есть ~1.5 секунды на **«Отменить отправку»** — если запись
   вышла неудачной, можно не тратить токены на транскрибацию.
4. **Проверить на ошибки** — отправляет текущий текст отдельным запросом на текстовую
   модель, которая чистит орфографию, пунктуацию и слова-паразиты. Если включено
   «Исправлять ошибки сразу после транскрибации», это происходит само: правится только
   что расшифрованный фрагмент, а не всё поле, поэтому уже исправленный текст не уходит
   на модель повторно. Кнопка остаётся для ручного запуска — например, после того как
   вы допечатали что-то руками. Сырой текст попадает в поле до автоправки, так что
   при сбое правки надиктованное не теряется.
5. **Копировать** — копирует текст из поля результата в буфер обмена.
6. **🕘 История** (значок в шапке) — последние 50 транскрибаций/исправлений с датой и
   возможностью скопировать каждую отдельно. Хранится локально, в файле профиля
   пользователя; можно очистить кнопкой в этом же окне.
7. Внизу поля результата — стоимость в рублях: за последний запрос и за всю сессию
   (берётся из ответа polza.ai; если провайдер её не прислал — «—»).

## Незавершённые записи

Надиктованное не теряется, даже если запрос завис, упал или приложение закрыли:

- Сразу после остановки записи аудио сохраняется на диск, ещё до отправки. Файл
  удаляется только после успешной расшифровки или вручную (в т.ч. «Отменить отправку»).
- **Таймаут**: 60 секунд на запрос, для записей длиннее минуты — больше (+1 с на каждые
  2 с сверх минуты, максимум 5 минут). По истечении запись попадает в незавершённые
  с понятной ошибкой, а не крутит индикатор бесконечно.
- **Сменить модель**: если ответа нет дольше 5 секунд, под статусом появляется кнопка
  «Сменить модель» — можно ввести название другой модели и отправить ту же запись
  заново. Зависший запрос при этом обрывается. Повторять можно сколько угодно.
- **📥 Незавершённые записи** (значок в шапке, красное число — сколько их): время
  записи, длительность, статус и последняя ошибка, число попыток и какие модели
  пробовали. Кнопки: прослушать, отправить заново (с выбором модели), удалить. Текст
  расшифрованной отсюда записи дописывается в поле результата и в историю.
- При запуске, если есть незавершённые записи, сверху показывается баннер со счётчиком.

Данные приложения (настройки, история, незавершённые записи) лежат в
`%APPDATA%\prikaz-golosom`: `config.json`, `history.json`, `unfinished.json` и папка
`recordings` с аудио. Имя папки зафиксировано в коде и не зависит от названия
приложения — после переименования «Приказ голосом» → «Prikaz golosom» настройки на месте.

## Правка текста, а не выполнение команд

Надиктовка часто сама является заданием («Сделай отчёт по задачам за два спринта...»).
Такой текст уходил модели в роли `user` как есть, читался как обращение к ней и
перебивал системную инструкцию: `gpt-4o-mini` выполняла задание вместо правки опечаток
и выдумывала содержимое целиком. Защита состоит из двух частей, обе в коде:

- текст передаётся в рамке `<text>...</text>`, что отделяет данные от инструкции;
- к промпту всегда приклеивается `PROMPT_GUARD` — запрет выполнять, продолжать и
  отвечать на текст, запрет добавлять что-либо от себя и требование сохранить объём.

`PROMPT_GUARD` идёт после пользовательского промпта (последняя инструкция держится
моделью лучше) и не редактируется из настроек. В версии 1.2.3 запрет лежал внутри
редактируемого поля, поэтому на машинах с правленым промптом защиты не было вовсе —
с 1.2.4 это невозможно.

## Релиз через GitHub Actions

Сборка и публикация автоматические, локальный `gh` и Windows-машина не нужны:

```bash
# в package.json уже лежит нужная версия
git tag v1.2.4
git push origin main --tags
```

Workflow `.github/workflows/release.yml` на `windows-latest` проверяет, что тег совпадает
с версией в `package.json`, собирает `npm run dist`, считает `.sha256`, убеждается, что
portable-ассет назван так, как ждёт `updater.js`, и публикует релиз. Если файла
`RELEASE_NOTES.md` нет, описание генерируется из коммитов.

Прогон из вкладки Actions вручную (`workflow_dispatch`) собирает сборку и кладёт её в
артефакты прогона, но релиз не публикует — удобно проверить сборку перед тегом.

## Сборка .exe для Windows (локально)

```bash
npm run dist
```

В папке `dist/` появятся:
- `prikaz-golosom-setup-<версия>.exe` — установщик (NSIS)
- `prikaz-golosom-portable-<версия>.exe` — portable-версия без установки

Установленное приложение и ярлык называются «Prikaz golosom».

exe не подписаны цифровой подписью — при первом запуске Windows SmartScreen может
показать предупреждение, снимается через «Подробнее → Выполнить в любом случае».
